# Security Policy – Pasindu Dilshan Portfolio

## Supported Versions

We actively support the current production release of this portfolio application with security updates and dependency hardening.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of our systems and user data very seriously. If you discover a security vulnerability, please report it responsibly through the following process:

1. **Email Contact**: Send details of the vulnerability directly to **dpasindu487@gmail.com**.
2. **Report Details**: Include a description of the flaw, steps to reproduce, and potential impact.
3. **Response Timeline**: You can expect an initial acknowledgment within 48 hours and a status update within 5 business days.
4. **Coordinated Disclosure**: Please refrain from publicly disclosing the vulnerability until we have verified and patched the issue.

Thank you for helping keep this project secure!
